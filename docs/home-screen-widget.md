# 휴대폰 홈 화면 위젯

Android와 iOS에서 오늘 날짜와 다가오는 일정을 표시합니다. 공유 데이터는 현재 달과 다음 달의 일정(최대 500개)을 포함하며, 한도를 넘으면 오늘 이후 일정을 우선합니다. 앱에서 보이는 개인 캘린더 및 가져온 일정(반복 일정 포함)을 사용합니다. 일정 변경과 앱 복귀 시 데이터를 갱신하며, 위젯 자체는 날짜 변경 및 운영체제의 주기적 갱신을 반영합니다. 서버를 직접 조회하지 않으므로 앱을 오래 열지 않으면 최신 변경은 앱을 다시 열어야 반영됩니다.

- Android: 홈 화면을 길게 누르고 **위젯 → 일상 캘린더**를 추가합니다. 소형(2×2), 중형(4×2), 대형(4×4)을 선택할 수 있으며 각각 최대 2개·3개·6개 일정을 표시합니다. 홈 화면 격자 설정에 따라 실제 칸 수와 크기가 달라질 수 있습니다. 크기를 조절하면 배치와 표시 개수가 가용 공간에 맞게 바뀝니다.
- iPhone: 홈 화면 편집에서 **위젯 추가 → 일상 캘린더**를 선택합니다. 소형·중형·대형을 지원합니다. 기존 Live Activity 확장에 함께 포함됩니다.
- Android 위젯 종류: **일정 목록**(소형·중형·대형), **오늘의 하루**(큰 날짜와 오늘 일정), **다음 일정**(진행 중 또는 곧 시작할 일정), **월간 달력**(오늘 강조와 일정 있는 날 표시). 다음 일정은 종료된 시간 일정을 제외하며, 같은 날의 시간 일정을 종일 일정보다 우선합니다. 월간 달력은 일요일부터 시작합니다.
- Android의 모든 크기는 기기 라이트·다크 모드를 따릅니다. 라이트 모드는 흰 배경과 진한 글자, 다크 모드는 어두운 배경과 밝은 글자를 사용합니다. 색상은 런처가 위젯을 다시 표시할 때 기기 설정으로 선택하며, 앱 실행 중 설정 변경 시에도 위젯을 갱신합니다.
- 위젯을 누르면 앱이 열립니다. 로그아웃 시 일정 내용을 지우고 로그인 안내를 표시합니다.

## iOS 실기기 서명

Apple Developer의 App Groups에 `group.com.zetto.calendarAppFlutter`를 등록하고 Runner와 CalendarLiveActivity의 App ID 및 프로비저닝 프로파일에 모두 활성화해야 합니다. 두 타깃의 entitlement는 저장소에 설정되어 있습니다. 시뮬레이터 빌드는 이 등록 없이 가능합니다.

## 데이터와 갱신

네이티브 공유 저장소에는 표시용 날짜·시간·길이·제목·색상만 전달합니다. 로그인 토큰, 계정 ID, 일정 설명, 위치는 전달하지 않습니다. 최대 500개의 일정을 저장하고 제목은 120자로 제한합니다. 위젯 갱신의 실제 시점은 운영체제에서 조정할 수 있습니다.
